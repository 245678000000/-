

# 🔮 塔罗牌抽牌与解读网站 — 完整实现计划

## 设计基调
**简约现代 × 玄学浓郁**：黑白灰为主色调，金色/紫色作点缀，排版留白大方，但文案保持韦特塔罗传统口吻，营造"高级神秘感"。

---

## 第一阶段：基础架构与数据层

### 1. 项目架构搭建
- 建立清晰的目录结构：`pages/` `components/` `hooks/` `utils/` `api/` `data/` `i18n/` `types/`
- 定义所有 TypeScript 类型（TarotCard、DrawnCard、ReadingResult、JournalEntry、SpreadType 等）
- 实现可复现随机算法（seeded random），确保同一天+同问题+同牌阵 = 同结果

### 2. 78张牌完整数据
- 大阿卡纳 22 张 + 小阿卡纳 56 张（权杖/圣杯/宝剑/钱币各14张）
- 每张牌包含：中英文名、正逆位含义（玄学口吻）、关键词、象征元素
- 文案风格：韦特塔罗传统语气，有仪式感和神秘感

### 3. 模拟 API 层
- `fetchAllCards()` / `fetchCardById()` / `drawCards()` 
- 模拟 400-900ms 延迟、10% 失败率（可配置）

### 4. 中英文国际化
- 全站 UI 文案中英切换，语言偏好持久化到 localStorage
- 牌名、正逆位标识、牌阵名称均有中英对照

---

## 第二阶段：核心页面实现

### 5. 首页 (`/`)
- 简洁引导页，展示网站主旨
- 快速入口：开始抽牌、浏览牌库
- 氛围感设计，简约但有神秘气质

### 6. 抽牌页 (`/draw`)
- 问题输入框（可选填）
- 牌阵选择：单张牌 / 三张牌（过去-现在-未来）
- 抽牌按钮（含 loading、禁用、错误提示状态）
- "重新洗牌"按钮（更换 salt 改变结果）
- 抽牌后跳转解读页

### 7. 解读结果页 (`/reading`)
- 牌阵标题 + 用户问题展示
- 每张牌卡片：牌名（中/英）、正逆位标识、关键词标签、核心含义（2-4句玄学语气）、建议行动（Do/Don't）
- 综合解读区：3-6句总结 + 一句话结论
- 单张牌模式下显示"是/否"倾向
- 操作：复制分享文案、保存到记录、再抽一次

### 8. 牌库页 (`/cards`)
- 78张卡片网格（移动端2列，桌面4列）
- 模糊搜索（中/英牌名）
- 过滤：大/小阿卡纳、按花色
- 排序：编号/热度
- Skeleton 加载态 + 空状态

### 9. 单牌详情页 (`/card/:cardId`)
- 正位/逆位含义详解
- 象征元素（行星、元素、数字学、占星对应）
- 正位/逆位各一组关键词
- "生活场景解释"（贴近实际的解读）
- 相关牌推荐

### 10. 记录页 (`/journal`)
- 显示最近50条抽牌记录（localStorage）
- 每条含：时间、问题、牌阵、抽到的牌、一句话结论
- 查看详情（只读回放模式）
- 删除单条 / 清空全部 / 导出 JSON

### 11. 关于页 (`/about`) + 404页
- 免责声明（中英双语）
- 404 页面
